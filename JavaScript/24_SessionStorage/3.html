Conclusión del Experimento

En esta última pantalla se consolida el ciclo de vida del almacenamiento en el navegador:

Código para comprobar Session Storage:

let nombreSesion = sessionStorage.getItem("Nombre"); if (nombreSesion === null) { document.getElementById("mensaje").innerHTML = "Resultado: null en SessionStorage."; } else { document.getElementById("mensaje").innerHTML = "Dato encontrado: " + nombreSesion; }

Código para comprobar Local Storage:

let nombreLocal = localStorage.getItem("Nombre"); if (nombreLocal === null) { document.getElementById("mensaje").innerHTML = "Resultado: null en LocalStorage."; } else { document.getElementById("mensaje").innerHTML = "Dato encontrado: " + nombreLocal; }
  • El valor es null: Como el segundo fichero ejecutó la orden de borrado, al intentar leer la clave aquí, el navegador devuelve un vacío (técnicamente null).
  • Verificación visual: Compruebas en tiempo real que los datos han desaparecido por completo del equipo local.

Resumen de buenas prácticas:

  1. Usa localStorage para preferencias de usuario duraderas (como activar el modo oscuro).
  2. Usa sessionStorage para procesos de un solo uso (como los pasos de un formulario de compra).
  3. Seguridad: Nunca guardes información confidencial como contraseñas, datos bancarios o tokens críticos en ninguno de los dos, ya que son vulnerables a scripts maliciosos (ataques XSS).
