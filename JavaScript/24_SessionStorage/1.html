¿Cómo funciona el Almacenamiento Web?

Tanto localStorage como sessionStorage permiten guardar datos clave-valor en el navegador del usuario. No se envían al servidor en cada petición HTTP, lo que los hace rápidos y eficientes.

1. Local Storage (Almacenamiento Local)

Este es el código que se está ejecutando actualmente en esta página:

// Comprueba si ya existe el nombre para no repetir el prompt if (!localStorage.getItem("Nombre")) { let nombreIngresado = prompt("Escribe tu nombre:"); if (nombreIngresado) { localStorage.setItem("Nombre", nombreIngresado); } } let nombreGuardado = localStorage.getItem("Nombre") || "Usuario Anónimo"; document.getElementById("mensaje").innerHTML = "Hola, " + nombreGuardado;
  • Persistencia: Los datos no expiran nunca. Permanecen guardados aunque cierres el navegador, apagues el ordenador o reinicies la sesión.
  • Alcance: Compartido entre todas las pestañas y ventanas que tengan el mismo origen (mismo dominio, protocolo y puerto).
  • Capacidad: Aproximadamente 5MB-10MB según el navegador.

2. Session Storage (Almacenamiento de Sesión)

Este es el código equivalente si prefieres guardar la información únicamente durante la sesión activa:

// Comprueba si ya existe el nombre para no repetir el prompt if (!sessionStorage.getItem("Nombre")) { let nombreIngresado = prompt("Escribe tu nombre:"); if (nombreIngresado) { sessionStorage.setItem("Nombre", nombreIngresado); } } let nombreGuardado = sessionStorage.getItem("Nombre") || "Usuario Anónimo"; document.getElementById("mensaje").innerHTML = "Hola, " + nombreGuardado;
  • Persistencia: Los datos son temporales. Se eliminan automáticamente cuando el usuario cierra la pestaña o la ventana del navegador.
  • Alcance: Limitado estrictamente a la pestaña de origen. Abrir la misma URL en una pestaña nueva genera una sesión independiente.
  • Capacidad: Alrededor de 5MB.

Métodos principales (idénticos para ambos):

  • setItem(clave, valor): Guarda un dato.
  • getItem(clave): Recupera un dato guardado.
  • removeItem(clave): Elimina un dato específico.
  • clear(): Borra todo el almacenamiento del dominio.
