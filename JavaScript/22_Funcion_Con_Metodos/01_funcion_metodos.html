🏗️ "this" en Métodos Prototípicos

Al definir métodos en el prototype, this se refiere a la instancia específica del objeto que llama al método. Esto permite que todas las instancias compartan la misma función pero accedan a sus propios datos (como su nombre o edad), ahorrando memoria.

💻 Código del Ejemplo

function Persona(nombre, edad) {
  this.nombre = nombre;
  this.edad = edad;
}

Persona.prototype.saludar = function () {
  return `Hola, soy ${this.nombre} y tengo ${this.edad} años`;
};

const persona2 = new Persona("Toni", 34);
console.log(persona2.saludar());
