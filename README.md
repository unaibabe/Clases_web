# Clases Web

Repositorio con los ejercicios y prácticas realizados durante el curso **IFC0210** del SEPE, centrado en el desarrollo web en entorno cliente.

Actualmente se están trabajando tecnologías como:

- HTML5
- CSS3
- JavaScript
- Programación asíncrona
- Promesas
- async / await

---

## Objetivo del repositorio

Este proyecto sirve como espacio de práctica y aprendizaje donde se recopilan los ejercicios realizados en clase, pruebas de concepto y ejemplos relacionados con el desarrollo frontend.

La idea es mantener una evolución progresiva desde conceptos básicos hasta funcionalidades más avanzadas de JavaScript moderno.
