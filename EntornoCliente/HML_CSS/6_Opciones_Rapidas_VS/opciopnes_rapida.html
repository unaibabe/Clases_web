Atajos VS

Si pulsamos la etiqueta y * lo multiplica, ej div*8

Si ponemos etiqueta y punto se crea con la clase. Ej: div.nombreClase

Y si se pone # se crea el id. Ej div#tal*4

Tambien se puede abrebiar poniendo punto solamente .className

Para poner nombre dentro de elementos y numerarlos se poner div{nombre $}*4

nombre 1
nombre 2
nombre 3
nombre 4

Para numerar pero con id div#nombre$*3

Para hacer listas tambien sirve ul>li*4

  • nombre 1
  • nombre 2
  • nombre 3
  • nombre 4
