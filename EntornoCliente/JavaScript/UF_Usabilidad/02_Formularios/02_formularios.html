Apuntes: Usabilidad en Formularios HTML

Conceptos clave de accesibilidad y usabilidad:

  • Etiqueta <label>: Vincula el texto al input mediante el atributo for. Al hacer clic en el texto, el foco va directo al campo.
  • Atributo name: Es la clave que identifica el dato cuando viaja al backend. Sin él, no se envía nada.
  • Atributo id: Identificador único para conectar con el label y aplicar CSS o JavaScript.
  • Atributos nativos (required y placeholder): Validaciones directas del navegador que ahorran código.
  • Atributo alt (Alternativo): Se usa en imágenes o botones para que los lectores de pantalla lo lean en voz alta.
  • Atributo title: Muestra una ayuda visual flotante nativa al pasar el ratón.
  • Clip-path interactivo: Permite recortar elementos mediante coordenadas geométricas (`polygon`) para crear formas personalizadas como flechas de mensajes directos en CSS.
