¿Qué acaba de pasar con los datos?

Este fichero demuestra cómo recuperar la información guardada por el archivo anterior y cómo realizar tareas de limpieza en el navegador:

Código ejecutado para Local Storage:

let nombreRecuperado = localStorage.getItem("Nombre"); if (nombreRecuperado) { document.getElementById("mensaje").innerHTML = "Hola de nuevo, " + nombreRecuperado; } else { document.getElementById("mensaje").innerHTML = "No se encontraron datos."; } localStorage.removeItem("Nombre"); localStorage.clear();
  • Lectura (getItem): El navegador busca la clave "Nombre". Si venías del primer fichero, mostrará el nombre que escribiste porque los datos persisten entre páginas.
  • Eliminación selectiva (removeItem): Borra exclusivamente la clave especificada de la memoria del navegador. Las demás claves intactas permanecen.
  • Limpieza total (clear): Vacía por completo todo el almacenamiento correspondiente a este sitio web (borra todas las claves existentes).

Diferencia en el ciclo de vida (Código para Session Storage):

let nombreRecuperado = sessionStorage.getItem("Nombre"); if (nombreRecuperado) { document.getElementById("mensaje").innerHTML = "Hola de nuevo, " + nombreRecuperado; } else { document.getElementById("mensaje").innerHTML = "No se encontraron datos."; } sessionStorage.removeItem("Nombre"); sessionStorage.clear();

Si usaras el código de arriba con sessionStorage, el nombre solo se leería con éxito si navegaste haciendo clic en el enlace. Si hubieras copiado la URL y abierto este segundo fichero en una pestaña nueva separada, el resultado habría sido null (vacío).
