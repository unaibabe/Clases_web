🏗️ Jerarquía de Clases y Reutilización

Aquí vemos cómo una única clase madre (Persona) sirve de base para dos tipos distintos: Alumno y Profesor. Ambas usan super() para no tener que repetir la lógica del nombre y la edad, pero cada una añade sus propios métodos y datos únicos.

💻 Código del Ejemplo

// Clase Base
class Persona { ... }

// Especialización 1
class Alumno extends Persona {
  mostrar_datos() { return `Alumno: ${this.nombre}...`; }
}

// Especialización 2
class Profesor extends Persona {
  datos_profesor() { return `Profesor: ${this.nombre}...`; }
}
