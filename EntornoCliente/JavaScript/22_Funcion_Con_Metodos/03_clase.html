🏗️ Clases (ES6)

Las clases son "plantillas" para crear objetos. Dentro del constructor, this inicializa las propiedades de la nueva instancia. En los métodos, this nos permite acceder a esos datos guardados en el objeto creado.

💻 Código del Ejemplo

class Persona {
  constructor(nombrePersona, edadP) {
    this.nombre = nombrePersona;
    this.edad = edadP;
  }

  presentarse() {
    return `Hola, soy ${this.nombre} y tengo ${this.edad} años`;
  }
}

const persona1 = new Persona("Monica", 45);
console.log(persona1.presentarse());
