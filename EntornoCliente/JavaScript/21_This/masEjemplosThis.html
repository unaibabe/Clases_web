💡 "this" en Constructores

Cuando usamos una Función Constructora con la palabra clave new, this apunta al nuevo objeto que se está creando. Es como una "plantilla" que rellena las propiedades del objeto vacío recién nacido.

💻 Código del Ejemplo

function Coche(marca, modelo) {
  this.marca = marca;   // Asigna marca al nuevo objeto
  this.modelo = modelo; // Asigna modelo al nuevo objeto
}

const miCoche = new Coche("Buga", "Modelo 3");
