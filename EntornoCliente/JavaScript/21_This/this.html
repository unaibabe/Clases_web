💡 Explicación de "this"

La palabra clave this hace referencia al contexto donde se ejecuta el código. Dentro de un método de un objeto, this apunta directamente al objeto que contiene ese método. Nos permite leer sus propiedades sin usar el nombre de la variable.

💻 Código del Ejemplo

const persona = {
  nombre: "Ana",
  saludar: function() {
    return "Hola, soy " + this.nombre; // this = persona
  }
};
