💡 "this" en Event Listeners

Cuando usamos una función normal como manejador de eventos, this hace referencia al elemento HTML que disparó el evento. Es muy útil para modificar el estilo o el texto del elemento que el usuario acaba de tocar sin tener que buscarlo de nuevo con su ID.

💻 Código del Ejemplo

const btn = document.getElementById("btnCrear");

btn.addEventListener("click", function() {
// Usamos 'this' para acceder a las propiedades del botón
this.style.backgroundColor = "#2ecc71"; // Cambia a verde
this.style.transform = "scale(1.1)";
this.textContent = "¡Soy 'this'!";

document.getElementById("mensaje").innerHTML = 
    "El botón ha cambiado su propio estilo usando this";
});
;
