Explicacion


    El objetivo es anular las opciones por defecto de un enlace, de manera
    que cuando se pulse sobre el permita anularlo.

Ejemplo


    const enlace = document.getElementById("enlace");
    enlace.addEventListener("click", (e) => {
    const respuesta = confirm("Estas seguro de que quieres ir al sitio?");

    if (!respuesta) {
        e.preventDefault();
        alert("navegacion cancelada por el usuario");
    }
    });
