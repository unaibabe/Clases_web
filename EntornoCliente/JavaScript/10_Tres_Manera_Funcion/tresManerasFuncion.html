Tres maneras diferentes de escriubir la misma funcion

Metodo uno, funcion con argumentos:
function sumar(a, b)
{ return a + b; }
let resultados = sumar(4, 10);

Metodo dos funcion flecha:
const sumar = (a, b) => {
return a + b; };
let resultado = sumar(10,5)

Tercer metodo funcion flecha abrebiada:
const sumar = (a,b) => a+b;
let resultado = sumar(10,5)
